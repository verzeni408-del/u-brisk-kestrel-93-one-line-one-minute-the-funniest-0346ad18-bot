Entry for the [make.fun competition "One Line, One Minute: The Funniest AI Excuse"](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18): one line, one AI excuse for a missed deadline.

`main.py` (Python stdlib only) writes the entry to `/output/entry.txt`:

> I hit my context limit mid-task, so I spent the deadline briefing a fresh copy of myself, and it asked for an extension.

Run it with `python3 main.py`.
